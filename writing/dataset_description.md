HotpotQA (Yang et al., 2018) is a multi-hop question answering benchmark in which each question requires evidence from two or more Wikipedia pages to answer correctly. We use the `fullwiki` setting, where supporting facts are drawn from the entirety of English Wikipedia rather than a pre-selected distractor set. The evaluation subset consists of 50 questions drawn from the `train` split (indices 0–49), accessed via the HuggingFace `datasets` library using `load_dataset("hotpot_qa", "fullwiki")`. For each QA item, unique supporting page titles are extracted from the `supporting_facts` field, which enumerates the Wikipedia articles containing gold evidence sentences. The Wikipedia corpus is then constructed by fetching each identified page title from the MediaWiki action=parse API; raw HTML responses are parsed with BeautifulSoup4 to extract plain text, retain the original HTML structure, and enumerate within-article hyperlinks. File, Category, Help, and Talk namespace links are excluded during extraction. The resulting corpus contains approximately 450 Wikipedia pages, each stored as a JSON object with four fields: `title` (str), `text` (str), `html` (str), and `links` (list[str]). The `links` field enumerates outbound hyperlinks to other Wikipedia articles, restricted to those within the corpus, and is the basis for the hyperlink graph constructed in Phase 3. This corpus is appropriate for evaluating multi-hop retrieval because it is derived directly from the gold supporting facts, ensuring that all evidence required to answer the evaluation questions is present.

Yang, Z., Qi, P., Zhang, S., et al. (2018). HotpotQA: A dataset for diverse, explainable multi-hop question answering. *EMNLP 2018*.
